# 泥沙水净化实验 · Phase标注方案

当前版支持Phase／Action筛选切换。Phase标阶段区间，Action按所选阶段筛选动作标签；Step／State暂不直接标注。评分表保留10项、满分18分。首次仔细观察阈值已经用户确认统一为≥3秒。

## 一、标注方法

选择阶段标签，在时间轴拖拽创建区间；点击区间选中，再拖动边界或在Regions详情中精确编辑。当前仅显示teacher1；Phase区间不可重叠，允许留白，也允许阶段在后续轮次中再次出现。实验轮次在区间详情填写，不自动推断。

## 二、Phase边界

| Phase | 名称 | 起点 | 终点 |
| --- | --- | --- | --- |
| Q | 观察与诊断 | 开始对原水样作观察／诊断 | 转入取样、处理或搭建 |
| PD | 水样预处理 | 开始取样、搅拌、沉降或对原水投药 | 转入装置搭建或过滤等下一目的 |
| DA | 装置搭建 | 开始装填、封装或固定过滤装置 | 装置就绪或转向进液 |
| F | 过滤操作 | 开始向过滤装置进液 | 该轮过滤与收集完成，转向其他操作 |
| C | 滤液处理 | 对已收集滤液开始投药、混匀或静置 | 转向再过滤、结果观察等下一目的 |
| E | 结果检验 | 首次过滤／处理后开始观察滤液 | 结束观察并转向改进或记录 |
| R | 迭代改进 | 开始体现改进方案的判断或调整行为 | 进入后续常规执行或结束探究 |
| E2 | 结果再检验 | 后续过滤／处理后再次开始观察滤液 | 观察结束并转向下一轮或记录 |
| S | 最终记录 | 开始确认并记录最终结果 | 最终记录完成或录像结束 |

R不覆盖整轮后续实验：有可见的改装／步骤调整时记R，之后常规进液仍记F，对滤液投药仍记C，观察记E2。改进过程中的动作编码按其任务目的使用R下L／M；后续常规执行使用对应DA／F／C等编码，避免重复覆盖相同证据。无需强制出现全部Phase。

DB装置状态通过评分项记录，不另作时间轴分段；S用于最终记录Phase。原表两次E改为E与E2，以区分首次与再次检验。

## 五、评分表（满分18分）

评分按整份录像汇总，每项只计一次；各轮证据写入评分理由。原表未指定多轮得分取首轮、末轮还是最高表现，暂不做自动选择。证据涉及多轮且结论不同时，保留各轮证据并待研究负责人确定汇总规则。

### 1. 观察水样（Q1，2分）

- 0分：未观察：接触水样容器后1秒内即开始倾倒，视线未在液面停留。
- 1分：简单观察：视线在水样上停留1秒至不足3秒（3秒归2分）。
- 2分：仔细观察：注视水样≥3秒；或眯眼、凑近、举杯对光、轻摇观察。

### 2. 取水样（PD1，1分）

- 0分：将全部水样用于实验，无水样留存。
- 1分：仅取用少量水样开展实验，剩余水样保留不作使用。

### 3. 装填滤层（DA1，2分）

- 0分：滤料填入无层次，所有材料混合倒入。
- 1分：粗细颠倒（细砂在上、粗砂在下），或脱脂棉不在出水端。
- 2分：最终装置从上到下为粗砂→细砂→棉／纸。

### 4. 过滤装置状态（DB1，3分）

- 0分：有效滤层n=0：无滤材，或仅有瓶盖无滤料。
- 1分：有效滤层n=1：一种材料形成有效层。
- 2分：有效滤层n=2：两种材料形成有效层。
- 3分：有效滤层n≥3：种类包括脱脂棉、细砂、粗砂。

### 5. 进液（F1，1分）

- 0分：过滤层塌陷。
- 1分：玻璃棒引流或分次倾倒，流速平稳且滤层未塌陷；直接倾倒但未塌陷同样记1分。

### 6. 加入氯化铁溶液（C1，2分）

- 0分：不滴加，直接重新搭建装置或继续后续操作。
- 1分：加氯化铁≥3滴。
- 2分：滴加氯化铁1—2滴。

### 7. 出水观察（E1，2分）

- 0分：不检验：过滤完成后2秒内无视线停留，直接倒掉、放置一旁或进入下一轮。
- 1分：短暂注视滤液不足3秒，无对比、无辅助动作。
- 2分：与原水或自来水并排置于白纸／白墙背景对比；或举杯对光、倾斜、轻晃且注视≥5秒。

### 8. 方案调整（R1，2分）

- 0分：停止迭代；或仅简单重复首轮过滤且滤液无澄清改善。
- 1分：以下三类有效调整实现1类。
- 2分：以下三类有效调整实现≥2类。

有效调整按三类统计，同类不重复计数：①新增氯化铁，或减少原有用量／不再滴加；②过滤操作≥2次；③更换滤料、调整层序或增减层数。单纯增加滴数不是原评分表明确认可的有效调整，M5也不直接等于2分。

### 9. 再次出水观察（E2_1，1分）

- 0分：无对比观察，直接判断过滤效果是否达到任务条件。
- 1分：与原水或自来水并排置于白纸／白墙背景对比；或举杯对光、倾斜、轻晃且注视≥5秒。

### 10. 最终溶液（S1，2分）

- 0分：与原水并排对比仍明显浑浊，无明显变化。
- 1分：明显变清，但边缘模糊，或有轻微颜色、细微悬浮颗粒。
- 2分：完全透明，无可见沉淀。

## 六、编号整理与待确认边界

| 原表 | 本版 | 理由 |
| --- | --- | --- |
| P观察与诊断／B取样 | PD／B取样 | 对齐评分表“水样预处理”，避免P与PD分裂 |
| C水样预处理／D投加助滤与沉降剂 | PD／D | 依据操作对象区分原水与滤液 |
| C滤液处理／三个H1 | H0、H1、H2 | 消除重复ID |
| E结果检验与E结果再检验 | E、E2 | 保留首次与后续检验区别 |
| DB装置搭建 | DA下DB State | 状态证据与搭建动作分层 |
| A1 1—3秒、A2 5秒以上 | A1为1≤t<3；A2为t≥3或辅助观察 | 用户已确认采用评分表≥3秒 |

待确认项目：

- 首次结果检验：3—5秒、无对比也无辅助动作的分值未规定，暂留空。0分和1分判据也未穷尽所有行为。
- 首次观察不足1秒且不完全满足原0分条件时，暂不擅自补判。
- 首次／再次结果检验中的“≥5秒”是否同时约束并排对比，原句存在解释空间；当前保留原文的两支结构，不由程序自动评分。
- 多轮实验中装填、进液、加药等评分按首轮、末轮、最高表现或其他规则汇总，原表未规定；由研究负责人统一前保持人工复核。
- 二次检验没有发生、原水或滤液不在画面内、滴数不可辨等情形不自动记0分，在证据中说明。


## 使用顺序

先选择视频与标注员，再依据任务目的划分Phase，最后对照录像逐项评分并填写时间证据。重复过滤在新一轮填写轮次；同轮分次进液不另起轮次。只根据实际可见行为标注，不从分数反推阶段，也不以缺少阶段区间直接判0分。

## Action标注与筛选

选择阶段后切换Action，标记该阶段对应的具体行为区间。Phase与Action独立保存，时间可重叠；不同Action可并行，相同Action的区间不可重叠。Action起终点按照可见行为标记，不自动套用Phase的边界。未发生行为的A0／H0等标签应标记所检查的判断窗口，在证据里说明依据；遮挡不能当作未发生。当前行为序列仍只由Phase生成。

完整Action词典以“data/annotation-schema.json”为准，原H1重码已整理为H0不处理、H1加1—2滴、H2加≥3滴，首次A2按用户确认使用≥3秒阈值。
