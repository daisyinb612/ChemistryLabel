# 泥沙水净化实验 · 视频标注操作指南

[打开在线标注工具](https://daisyinb612.github.io/ChemistryLabel/)

工具支持视频播放、Phase阶段分段、Action动作标注、行为序列、实验评分和CSV导出，默认标注员为 **teacher1**，可点击顶部“＋”新增标注员。缩小窗口时，右侧面板会自动移到视频下方；手机宽度下改为单列，可继续滚动使用各项功能。

## 1. 导入视频

- 点击左侧 **导入 URL**，粘贴视频直链；多个链接每行一个。建议使用可直接播放的HTTPS链接，网盘分享页面不能直接作为视频链接。
- 或在左侧 **本地视频** 下点击原生文件选择按钮（“选择文件”），选择电脑中的实验录像。本地录像不会上传。
- 导入后，在左侧任务列表中点击视频即可切换。同一次打开网页期间，切换任务不需要重复选择本地录像；刷新或重新打开网页后需要再次选择相同文件。
- 若内嵌预览浏览器没有弹出系统文件窗口，请复制在线网址到Chrome、Edge或Safari中选择文件。

播放器内支持播放／暂停、进度拖动、音量及全屏操作。选择文件后，页面显示文件名；浏览器不会向网页公开完整磁盘路径。

本地预览可访问 `http://127.0.0.1:8765/`，并点击“载入本地测试视频”播放测试文件；线上页面不显示此测试入口。

## 新增与切换标注员

点击顶部标注员标签旁的 **＋**，输入名称后点击“创建并切换”。名称不能重复。点击已有标注员标签即可切换，各人的分段、评分和备注分别保存，刷新后保留当前选择。标注身份保存在当前浏览器中，不会自动跨设备同步。

## 2. 标注 Phase 阶段

1. 在视频下方选择阶段，例如“Q观察与诊断”或“PD水样预处理”。
2. 选择 **Phase** 模式。
3. 在时间轴空白处按住鼠标并拖拽，创建阶段区间。
4. 点击区间选中，拖动左右边缘调整起终点，拖动区间内部可整体移动。

Phase区间不能重叠，阶段可以在后续轮次中再次出现。可以缩放时间轴并水平滚动，精细调整边界。桌面布局下，Phase与Action时间轴都会填满各自的剩余空间。行为序列可在右侧同名标签页中查看。

## 3. 标注 Action 动作

1. 选择动作所属的阶段，再切换到 **Action**。
2. 下方会显示该阶段的动作标签，例如“A2仔细观察”。
3. 选择动作标签，在时间轴拖拽创建动作区间。

Phase和Action分别保存。Action可以与Phase覆盖同一时间段，不同动作可以并行，相同Action的区间不能重叠。切换阶段会筛选对应的动作标签和区间。

## 4. 编辑、删除和查看序列

- 点击时间轴区间，右侧自动切换到 **Regions区间**。
- 在详情中修改阶段、Action、起终点秒数、实验轮次和观察证据，点击 **保存修改**。
- 点击 **删除区间** 删除选中标注；可用时间轴上方的撤销、重做按钮恢复或重做操作。
- Regions中可按时间排序，也可隐藏区间；隐藏只影响显示，不会删除标注。
- 右侧 **行为序列** 标签页 按Phase区间的起点时间自动排列。修改、删除、撤销后同步更新；点击编码可定位对应片段。Action不会重复加入Phase序列。序列按时间顺序纵向排列，并显示阶段名称、轮次和时间。

## 5. 实验评分

1. 点击右侧 **实验评分**。
2. 逐项阅读判据并选择分数，共10项，满分18分。
3. 在文本框中填写时间区间、观察证据和得分理由；也可点击 **引用当前时间**。

证据不清时保留空白并注明原因，不要直接记0分。未评满10项时显示已评项目小计。首次“仔细观察水样”的时间阈值为 **≥3秒**，恰好3秒归2分；未明确的判分情形可参照[标注方案](docs/标注方案.md)复核。

## 6. 导出标注结果

点击右上角 **导出 CSV**，下载当前选中标注员各视频任务的Phase、Action和评分记录。

CSV包含视频名称与URL、标注员、轮次、Phase、Action、起终点、分数及证据。可用Excel打开；未评分为空，已评0分为数字0。

## 7. 保存、备份与迁移

- 标注自动保存在当前浏览器中，刷新网页后可以继续。
- 点击左下角 **备份数据**，导出完整JSON备份。
- 点击 **恢复备份**，选择此前导出的JSON文件，确认后恢复。恢复会替换当前浏览器中的项目数据，请先备份现有记录。
- 更换设备、浏览器，或从本地版转到在线版时，先备份JSON，再到新环境恢复。标注不会自动同步到其他设备或GitHub。

## 常用快捷键

| 按键 | 操作 |
| --- | --- |
| 空格 | 播放／暂停 |
| 1—9 | 选择或筛选阶段 |
| 左／右方向键 | 后退／前进1秒 |
| Delete | 删除选中区间 |
| Ctrl／⌘ Z | 撤销 |
| Ctrl／⌘ Shift Z | 重做 |

编辑输入框时不会触发上述标注快捷键。
