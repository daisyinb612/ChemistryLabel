# Chemistry Label · 泥沙水净化实验标注网页

Label Studio风格，当前只显示 **teacher1**。页面按窗口尺寸铺满，右侧用“实验评分／Regions区间”两个标签共享空间。支持 **Phase／Action筛选切换**，行为序列标签为20—22px。

## 打开

直接双击 `index.html` 或 `泥沙水净化实验视频标注器.html`，无需安装依赖。也可运行 `npm run dev` 后访问 `http://127.0.0.1:8765`。文件方式和HTTP方式的浏览器存储相互独立。

## 使用

1. 导入视频URL（每行一个视频直链），或选择本地视频。
2. 选择阶段，再切换 **Phase／Action**。Phase模式显示阶段区间；Action模式显示所选阶段对应的动作标签与动作区间。
3. 选中标签后，在时间轴拖拽创建区间。拖动边缘调整时间，拖动内部整体移动。
4. Phase区间不可重叠；Action可与Phase重叠，不同Action也允许并行。相同Action的区间不可重叠。并行动作会在当前轨道内分行显示。
5. 点击区间后，右侧自动切到Regions，可编辑阶段、Action、起终点、轮次与证据。点击“实验评分”切回评分。
6. 下方“行为序列”只由Phase区间按起点时间生成。修改、删除、撤销、刷新后同步更新；Action不会重复加入阶段序列。点击大标签定位对应Phase。
7. 在右侧按10项判据评分，满分18分。未评项目留空，不计作0分；未评满显示小计。
8. 导出CSV，包含teacher1在各视频任务中的Phase、Action与评分。Action代码、名称另有列；未评为空，0分为0。UTF-8 BOM，Excel可打开。

快捷键：空格播放／暂停；数字1—9筛选阶段；左右方向键跳转1秒；Delete删除选中区间；Ctrl／⌘ Z撤销，Ctrl／⌘ Shift Z重做。时间轴支持缩放和水平滚动。

## 数据与兼容性

标注保存在当前浏览器，尚无服务器账号或跨设备同步。页面只展示teacher1，其他既有标注员的数据不删除，仍保留在完整JSON备份中；当前CSV只导出teacher1。

使用“备份数据”导出JSON，“恢复备份”会确认后替换当前项目。兼容此前版本2的Phase区间（没有layer字段时按Phase读取），新Action带独立layer和action字段。旧版1.0的JSON不直接导入。

URL应为浏览器可播放的视频直链，网盘分享页不是视频文件。访问限制、过期链接、鉴权或不支持的视频编码可能导致载入失败。网页不代理下载。本地视频不上传，重新打开后需重新选择相同文件。

## 源文件

- `app.js`：标注、筛选、存储与导出。
- `app.css`：自适应布局。
- `src/template.html`：页面结构。
- `标注词典.json`：9个Phase、43个Action及10项评分；Step和State保留为原始参考，不在本版直接标注。
- `assets/icons.json`：界面图标。
- `node build.mjs`：生成两个独立HTML页面，修改源文件后需重新构建。
- `design-qa.md`：视觉与交互验收记录。

首次仔细观察阈值已确认≥3秒，恰好3秒归2分；其他判分边界参见“标注方案.md”。
